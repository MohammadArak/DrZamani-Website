## تجربه طراحی

- سربرگ کوتاه و تمرکز بر عکس‌ها؛ چیدمان سه‌ستونه دسکتاپ/دوستونه موبایل و نمای درشت دو/یک‌ستونه.
- فیلتر چسبان همه/نیم‌رخ/روبه‌رو/سه‌رخ، شمارنده نتیجه و تغییر نرم چیدمان با View Transitions در مرورگر پشتیبان؛ fallback بدون این API برقرار است.
- نمایشگر بزرگ با عکس کامل، قبلی/بعدی، بندانگشتی، کلیدهای جهت‌دار RTL و Escape؛ بازگشت فوکوس به عکس بازکننده.
- بزرگ‌نمایی۲× با اسکرول داخل عکس و بازگشت به نمای کامل؛ هیچ اسلایدر قبل/بعد جعلی ساخته نشده است.
- نشان‌کردن عکس از کارت یا نمایشگر، نوار انتخاب‌ها، فیلتر نشان‌شده‌ها و حالت خالی با پاک‌کردن فیلترها. نشان‌ها فقط در حافظه همان صفحه‌اند؛ نه storage/API و نه ارسال اطلاعات.
- کنترل توقف حرکت و پشتیبانی CSS/JS از prefers-reduced-motion؛ dialog بومی و دکمه‌های دارای نام دسترس‌پذیر.

## تصاویر و داده

شش تصویر عمومی موجود `public/img/samples/{1,2,3,4,8,12}.jpg` بدون تغییر فایل، برش قبل/بعد، فیلتر رنگ یا ساخت نتیجه جدید استفاده شدند. همه از قبل در گالری runtime موجود بودند. دسته‌بندی صرفاً زاویه قابل مشاهده عکس است: 1/3/4 نیم‌رخ، 2/12 روبه‌رو، 8 سه‌رخ. شناسه‌ها شماره فایل‌اند؛ تصاویر به بیمار، پرونده یا یک جلسه درمان مشترک نسبت داده نشده‌اند. نوع دقیق عمل، سن، جنسیت، فاصله زمانی و ادعای نتیجه تازه ساخته نشده است. رضایت انتشار این فایل‌های عمومی در این مرحله مستقلاً بازتأیید نشده؛ قبل از انتشار گالری جدید، metadata و رضایت به بررسی مالک/پزشک نیاز دارند. فایل خصوصی/پرونده بیمار و رسانه تازه‌ای وارد Git نشده است.

اطلاعات تماس فقط snapshot مقادیر fallback عمومی `src/config/clinicInfo.ts` است؛ تولید باید از ClinicInfoContext استفاده کند. رزرو/پرداخت فعال نشده‌اند و API/CMS یا route عمومی گالری جدید ساخته نشده است.

## اجرا و بررسی

`index.html` کنار `gallery.css` و `gallery.js` از دارایی‌های `../../../public/` استفاده می‌کند. نسخه portable با assets مستقل در `outputs/gallery-preview`، پیش‌نمایش loopback8094 و ZIP همراه handoff ارائه می‌شود. تاریخ/شاخه/شناسه دقیق source/merge/tree/CI در `outputs/gallery-preview/DELIVERY.json` ثبت می‌شود؛ نسخه محصول1.18.0 ثابت است.

بررسی مرورگر واقعی: دو چیدمان در عرض‌های1440/768/390/320، هشت حالت با clientWidth=scrollWidth و شش تصویر سالم؛ نمایشگر باز320 بدون overflow، عکس کامل/۲×/reset، بعدی و جهت‌دار، نشان از نمایشگر و بازگشت focus با Escape؛ فیلتر روبه‌رو۲، فقط نشان‌شده۱، حذف آخرین نشان→حالت خالی، پاک‌سازی→۶، تغییر سریع روبه‌رو→نیم‌رخ→سه‌رخ→۱ تصویر؛ کنترل motion-off با animationName=none. پنجره موبایل از ارتفاع ثابت با فضای خالی زیاد به ارتفاع متناسب اصلاح شد.

خطاهای مسیر: selector اولیه data-view بیش از دکمه‌ها را می‌گرفت؛ قبل از QA محدود شد. کلیک سریع حین View Transition توسط لایه انتقال گرفته می‌شد؛ pointer-events:none روی لایه انتقال و aria-busy با پایان transition اضافه و تغییر سریع مجدداً موفق شد. cache مرورگر یک بار JS قبلی را نگه داشت؛ query نسخه CSS/JS اضافه و بارگیری نسخه جدید با DOM تأیید شد. خواندن وضعیت قبل از پایان transition معیار قبولی نیست. جزئیات محلی تکمیلی و console در browser-checks.json خروجی است.

NOT RUN: تنظیم واقعی reduced-motion سیستم، screen reader، لمس/gesture دستگاه واقعی، Safari/Firefox و fallback بدون View Transition، سنجش field و ممیزی کامل WCAG. CI فقط پس از نتیجه واقعی در رسید PASS گزارش شود. هیچ deploy انجام نمی‌شود.

ابتدا بازخورد مالک فقط درباره گالری. پس از پذیرش، route گالری React و اتصال به CMS/رضایت و metadata واقعی، lazy responsive images، حفظ تصاویر کامل و اطلاعات معتبر هر تصویر. فیلترهای بالینی/خدمت فقط پس از داده تأییدشده اضافه شوند. قابلیت نشان موقت هنوز account/backend یا ثبت علاقه‌مندی بیمار نیست. صفحه اصلی فعلاً کنار گذاشته شده و طرح آن پذیرفته نشده است.
