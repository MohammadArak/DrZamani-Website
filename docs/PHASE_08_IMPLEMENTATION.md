# مرحله۸ — طراحی اجرایی و صفحات خدمات، نسخه1.17.0

مالک پس از بررسی پروژه، ادامه مستقل کار و گزارش نهایی را درخواست کرد. حوزه این PR اجرای طرح سرمه‌ای/طلایی موجود، موبایل، گالری فعلی و صفحات معرفی خدمات است؛ سایت زنده منتشر نشده است. پذیرش میدانی سرعت، Search Console و گیت‌های مرحله۱۰ جدا و ناتمام‌اند.

## رفتار نهایی

هیرو و هدر سرمه‌ای، نام طلایی، خدمات ساده، معرفی پزشک، نظرات عکس/نام/متن/سن اختیاری از API، گالری۱۶تصویر موجود با اسکرول دستی و بزرگ‌نمایی، مقالات منتشرشده، پرسش‌های تماس و نقشه/فوتر پیاده شدند. در موبایل، منوی کشویی و نوار تماس/مسیر/رزرو وجود دارد. آمار۲۰سال/۱۵هزارجراحی و وعده نتیجه درمان از متن معرفی قبلی حذف شد؛ مدرک/رضایت/نظر یا تصویر بیمار تازه اختراع نشده. گالری عمومی قبلی حفظ شد؛ رضایت هر تصویر موجود در این مرحله مستقل بازتأیید نشده است.

رفتار رزرو قبلی محفوظ است: CTA صفحه اصلی همیشه «رزرو نوبت»؛ خاموش→دیالوگ پیام مدیر، فعال→سامانه. /appointment/ خاموش هیچ فرم/ماژول بیمار/CAPTCHA بارگیری نمی‌کند. تماس، شهر، ساعات، شماره نظام پزشکی، نشانی و لینک نقشه از اطلاعات مرکزی مطب خوانده می‌شوند. سه کارت حذف‌شده AboutUs بازنگشتند. صفحه مستقل مقالات قالب قبلی خود را حفظ می‌کند.

کاروسل نظرات اکنون دستی است؛ هیچ حرکت خودکار/تایمر جدید ندارد. گالری native scroll-snap، دکمه‌های قابل نام‌گذاری، Escape، focus و reduced-motion دارد. placeholder قدیمی content-visibility برای بخش‌های طراحی تازه کنار گذاشته شد تا رسم پایین صفحه و طول سند با محتوای واقعی هماهنگ باشد. تصاویر WebP پزشک با اندازه ذاتی درست و تصاویر پایین صفحه lazy هستند. تصاویر گالری قبلی بازتولید نشده‌اند.

چهار صفحه خدمات و فهرست /services/ با HTML اولیه سرور، canonical، breadcrumb و 404 واقعی ساخته شدند. کاتالوگ واحد api/app/clinic_services.json هم در کارت‌های React و هم در API مصرف می‌شود؛ بک‌اند وابسته به وجود src نیست. متن صرفاً معرفی حوزه‌های موجود و راه هماهنگی است؛ محتوای تفصیلی پزشکی یا ادعای نتیجه جدید نیست. اطلاعات مطب تازه و escaped است. service HTML اسکریپت SPA را حذف می‌کند تا صفحه اصلی روی آن mount نشود. sitemap عمومی صفحات شناخته‌شده خدمات را با تاریخ واقعی و نسخه‌دار کاتالوگ/آخرین تغییر مطب اضافه می‌کند؛ تاریخ از زمان build/request تولید نمی‌شود. sitemap استاتیک فاقد lastmod ساختگی است؛ سرویس Nginx/API منبع اصلی sitemap و HTML خدمات است. templateهای HTTP/TLS مسیر services را با guard تعمیر به API می‌فرستند؛ تنظیم فعال سرور واقعی تغییر نکرد.

## شواهد محلی

- Node24.19.0، Python3.12.14 و Git runtime میزبان پیدا شدند. frontend npm ci آفلاین از cache با lock موفق؛ نصب شبکه اولیه شکست خورد. گزارش «۰ آسیب‌پذیری» آن نصب آفلاین جای ممیزی آنلاین تازه نیست.
- venv قبلی به پروفایل admin اشاره داشت؛ مسیر Python در فایل ignored pyvenv.cfg اصلاح شد و محیط دوباره قابل اجراست. frozen sync تازه Python به شبکه/DNS خورد و آفلاین هم همه wheelها موجود نبود؛ نصب تمیز محلی PASS نیست. frozen export موفق و۴۷بسته نصب‌شده با export ویندوز تطبیق شد، بدون dependency جدید. PHASE_08_DEPENDENCY_CHECKS.json مرجع است؛ CI checkout تمیز گیت پیش از ادغام است.
- fullpytest:۳۱۷passed/۱۴Linux-skipped/۳warning قبلی،116.69s. پس از تغییر نهایی SSR، مجموعه خدمات/تنظیمات/Nginx۴۴passed،18.84s. تست‌های sandbox نخست به ACLSQLite خوردند و اجرای مجاز با DBfixture مستقل گذشت؛ خطاهای transient نتیجه نهایی برنامه نیستند.
- چهار تست تازه خدمات: HTML/canonical/breadcrumb، redirect و404، تازگی مطب و escaping، sitemap پایدار و عدم درج پنل/نوبت. تست واقعی Nginx HTTP/TLS guard تعمیر مسیرهای خدمات نیز توسعه یافت؛ این اجرا VPS/systemd نیست.
- lint صفر warning، TypeScript/build1.17.0، Ruffcritical،۸فونت/206004bytes و bundle budgets موفق. build نهایی اطلاعات را از APIfixture واقعی خواند. gzipهای نهایی پیش از کامیت: main96142،staff24607،patientGate876،patientSession1551،allJs418815،CSS21098bytes؛ اعداد artifact هستند و LCP/INP میدانی نیستند.
- سه verifier migration عمومی/editorial/comments با داده پرشده و restore مستقل موفق؛ schema migration تازه لازم نبود. API مرورگر با DB جدید و۱۹migration، بدون حساب مالک و providerdisabled/bookingfalse بالا آمد.
- Edge واقعی desktop/mobile، عرض۱۴۴۰/۱۰۲۴/۷۶۸/۳۹۰/۳۲۰ بدون سرریز افقی؛ singleh1،۴خدمت،۱۶نمونه، منو، CTAخاموش، دیالوگ وEscape، بزرگ‌نمایی، سرویسSSR،404 و نبود ماژول بیمار در appointment بررسی شد؛ pageerror صفر. PHASE_08_BROWSER_CHECKS.json مرجع است. نظرات/مقالاتِ کارت‌های پرشده در تصاویر، فقط پاسخ mock مرورگر و صریحاً نمونه آزمایشی‌اند؛ درDB/سایت واقعی منتشر نشده‌اند.
- screenshots درoutputs خارجGit هستند؛ PNGهای نهایی بصری بازخوانی شدند. اندازه تصویر/متن فارسی/فاصله‌ها بررسی شد. fullPage مرورگر عناصر fixed را با موقعیت viewport ثبت می‌کند؛ نمای hero/mobile viewport نیز برای بررسی دقیق حفظ شود.

## موارد باز و ادامه

نتیجه CI نهایی، source/merge/tree وZIP/hash در رسید outputs پس از ارسال ثبت می‌شود. اسکن تاریخچه/کامیت نهایی پیش از merge لازم است. متن این گزارش ادعای نتیجه CI قبل از اجرای آن ندارد.

Search Console/Google crawl، field LCP≤2.5s/INP≤200ms/CLS≤0.1، بررسی مستقل کامل دسترس‌پذیری و بازبینی تخصصی محتوای پزشکی/رضایت دارایی‌ها در محیط واقعی انجام نشده‌اند. راهنمای SEO در PHASE_08_SEO_CHECKLIST.md است. بنابراین checkboxهای پذیرش خارجی مرحله۸ و کل مرحله۱۰ complete نیستند.

مرحله۱۰ همچنان actualVPS/systemd/runuser/jobs/WebSocket/HTTPS/configفعال، providerهایواقعی، هویت artifact/production، offsite encryption/retention و قطع‌برق را دارد. staging موجود نیست و سؤال تکراری مطرح نشود. هیچ deploy، productionbooking، realowner/payment/SMS یا داده خصوصی بیمار مجاز/اجرا نشده. commit/PR/merge حوزه آزموده از قبل مجاز است؛ deploy اجازه جدا می‌خواهد.
